# Video Compressor 1.3.3

Clearer, quieter interface.

### Changes
- Removed technical jargon and long help texts most people never need.
- Everyday options first: max size, audio level, keep sound.
- Advanced choices moved under **Meer opties** (acceleration, format, speed, concurrency).
- Plain labels: audio as Low/Normal/High, speed as Fastest/Normal/Better.
- Simpler status, details panel, and settings pages.

### Requirements
- Windows
- FFmpeg and FFprobe installed separately.

### Installation
Download `Video-Compressor-1.3.3-Setup.exe` and run the installer.

Note: This release is currently unsigned, so Windows SmartScreen may display a warning.
